# NOOR — Daily Muslim Companion

NOOR is a calm, mobile-first Islamic platform that combines daily worship tools,
Naat discovery, foundational learning, and carefully separated community
services in one simple interface.

## Included experience

- Daily prayer countdown, Qibla access, Quran reminders, Dhikr and Durood
- Searchable multilingual Naat library with writer and reciter collections
- Ahle Sunnat wal Jamaat introduction and a text-only family tree
- Five Pillars, Tawheed, Namaz, Roza, Zakat and Hajj learning paths
- Khanqah and Urs, Waqiyahs, festivals, Quranic quotes and FAQs
- Scholars, channels, institutes, madrasas, jobs and career discovery
- Privacy-first matrimony concept and category-based donation interface
- Responsive layout, dark mode, local saved Naats and Dhikr progress

## Important publishing notes

- Prayer times in this build are demonstration values for Bengaluru. Connect a
  trusted prayer-time service before relying on them.
- Religious rulings and historical content should be reviewed by qualified
  scholars before publication.
- Donation payments remain disabled until a verified organization and secure
  payment provider are connected.
- Matrimony profiles require moderation, identity checks and a privacy policy.
- Full lyrics must be added only with appropriate rights and source attribution.

## Local development

```bash
npm install
npm run dev
```

The project uses Next.js and React. `npm run build` automatically selects the
correct production build for Vercel or the retained NOOR site environment.
